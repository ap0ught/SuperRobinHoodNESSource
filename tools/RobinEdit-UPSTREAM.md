# Upstream Windows RobinEdit (dizzy9)

The archives in this folder (`RobinEdit.rar` = **0.4.4**, `RobinEdit v0.3.rar` = older **0.3**) are the original **Windows** RobinEdit utility by **Łukasz Kur** (**dizzy9**), distributed on [romhacking.net/utilities/1828](https://www.romhacking.net/utilities/1828/).

The maintained **React** remake lives in **[ap0ught/robinedit](https://github.com/ap0ught/robinedit)** (React port by [Christopher Mayfield / ap0ught](https://github.com/ap0ught)); the same archives (plus attribution) are kept there under [`upstream/`](https://github.com/ap0ught/robinedit/tree/main/upstream). Prefer that repo for the editor; do not commit `.nes` ROMs.
